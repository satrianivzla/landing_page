# Coming Soon Page CMS with CodeIgniter 3

This is a simple Coming Soon Page CMS built with CodeIgniter 3, Ion Auth, and Bootstrap 5. It allows you to easily manage the content of your coming soon page from an admin panel.

## Features

*   Content slider
*   About us section
*   Service section
*   Filtered gallery section
*   Contact form section with Google Map integration
*   WhatsApp floating button
*   Footer with social media links and legal pages
*   Admin panel to manage all content
*   Image upload with WebP support

## Requirements

*   PHP 5.6+
*   MySQL 5.1+
*   Composer

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/your-repo.git
    ```
2.  Install the dependencies:
    ```bash
    composer install
    ```
3.  Create a database and import the `database.sql` file.
4.  Configure the database connection in `application/config/database.php`.
5.  Configure the base URL in `application/config/config.php`.
6.  Run the migrations by navigating to `http://your-site.com/migrate`.
7.  Access the admin panel at `http://your-site.com/admin` and log in with the default credentials:
    *   **Email:** admin@admin.com
    *   **Password:** password

## Usage

1.  Log in to the admin panel.
2.  Navigate to the section you want to edit.
3.  Make your changes and save.
4.  The changes will be reflected on the coming soon page.
